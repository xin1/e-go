# Marker Assets

## 字典选择

当前你使用的 Find-GCP 自定义 3x3 字典建议写：

```text
--dictionary 99
```

如果使用普通 OpenCV ArUco 字典，则需要换成对应字典名，例如：

```text
--dictionary DICT_4X4_50
```
